## 2024-05-18 - [Server Actions Missing Input Validation]
**Vulnerability:** Next.js Server Actions were receiving input arguments without performing strict type or bounds validation. This could allow manipulating requests to pass arbitrary types (like objects) or out-of-bounds values (like negative numbers for points). Furthermore, any errors thrown by the database operations were not handled, which could leak internal server logic to the client.
**Learning:** Next.js Server Actions execute on the server but are directly invokable by the client. Therefore, every Server Action must independently validate the type, bounds, and length of its arguments, exactly like a traditional REST API endpoint, and secure its error handling mechanisms to return generic responses instead of detailed stack traces.
**Prevention:** Always implement `try/catch` blocks in Server Actions. Use strict validation logic for all function arguments (e.g. `typeof arg === 'string'`, `arg.length <= 255`, `Number.isInteger(arg)`, `arg > 0`) before executing database queries or processing the data.
